# ⏰ ChronoClock

### A Responsive Real-Time Digital Clock

ChronoClock is a lightweight digital clock built with HTML, CSS, and JavaScript. It provides a simple, clean interface for viewing the current time in a web browser.

## ✨ Features

- 🕒 Real-time clock display
- 🎨 Clean and user-friendly interface
- 📱 Responsive layout for different screen sizes
- ⚡ Lightweight implementation using vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 Preview

A simple and intuitive digital clock interface designed for everyday use.

## 🚀 Getting Started

### Prerequisites

A modern web browser.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/rihadev/ChronoClock-.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies are required.
